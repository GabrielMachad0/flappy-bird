# Flappy Bird

Recriação do Flappy Bird em um único arquivo HTML: Canvas 2D, sem framework, sem build e sem dependência externa.

- Física de gravidade e impulso, geração de canos e detecção de colisão
- Recorde salvo no navegador (`localStorage`)
- Efeitos sonoros gerados na hora com Web Audio, sem arquivo de áudio
- Joga no teclado ou no toque da tela, e se ajusta ao redimensionar

## Rodar

Abra `index.html` no navegador. É só isso.

## Stack

JavaScript puro · Canvas 2D · Web Audio API
